# 工作台隐私政策（功能测试版）

版本：2026-08-15.1  
生效日期：2026-08-15

> 正式销售前必须补充发行主体全称、注册地址、客服联系方式和隐私事务联系方式，并由发行方完成最终审查。

## 一、适用范围

本政策说明“工作台”在本机运行、管理案件和调用第三方模型服务时如何处理信息。

## 二、本机保存的信息

软件在本机保存工作区路径、案件基本信息及案件文件副本、用户创建或导入的 Skill、应用设置、会话与 Token 用量记录、受控浏览器数据以及运行日志。API Key 使用 Windows 安全存储加密保存，界面不会回显完整密钥。

## 三、发送至模型服务的信息

只有在用户使用 AI 功能时，用户输入、所选或引用的文件内容、必要的对话上下文、工具调用信息，以及 DeepSeek Harness 生成的稳定匿名用户标识和会话标识，才会发送至用户配置的模型服务。使用 DeepSeek API 时，接收方为 DeepSeek 开放平台，其处理活动同时受 DeepSeek 公布的协议和隐私政策约束。

“工作台”是独立开发和发行的第三方桌面软件，并非 DeepSeek 官方产品，与 DeepSeek 不存在联合开发、代理、认证、授权销售或品牌背书关系。DeepSeek 账户、API 服务、模型、余额、计费和平台条款由 DeepSeek 独立提供和管理。

## 四、案件和敏感信息

案件材料可能包含当事人、证人及其他人员的个人信息或敏感个人信息。用户应确认自己具有合法处理和发送相关信息的权限，并在发送前进行必要的筛选、脱敏和授权确认。不得提交国家秘密、无权披露的商业秘密或其他依法禁止传输的数据。

## 五、受控浏览器与遥测

受控浏览器仅访问经安全检查的公开 HTTPS 地址，关键网页操作需要用户逐次批准。软件默认关闭发行方遥测和 RTK 遥测，不会把案件内容上传到发行方服务器。第三方模型服务仍可能根据其自身规则记录 API 请求。

## 六、保存期限与用户控制

本机数据持续保存至用户主动删除。用户可以在案件目录和 Skill 管理中管理文件，可以在 API 页面清除密钥，并可通过 Windows 应用数据目录清除会话、浏览器数据和运行记录。卸载软件不会自动删除“我的文档”中的案件文件。

## 七、政策更新与联系

政策发生实质变化时，软件将再次请求确认。功能测试期间请通过软件取得渠道反馈隐私问题；正式销售版将提供明确的发行主体、客服和隐私联系方式。
