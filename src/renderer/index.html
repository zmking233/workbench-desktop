与 DeepSeek 的关系

“工作台”是独立开发和发行的第三方桌面软件，基于开源 DeepSeek Harness 构建，并允许用户使用自己的 DeepSeek API Key 连接 DeepSeek 开放平台。本产品并非 DeepSeek 官方产品，与 DeepSeek 不存在联合开发、代理、认证、授权销售或品牌背书关系。DeepSeek 账户、API 服务、模型、余额、计费和平台条款由 DeepSeek 独立提供和管理。

隐私政策摘要

工作区、Skill、设置和加密后的 API Key 默认保存在本机。只有在用户使用 AI 功能时，输入内容、所选文件内容、必要的会话上下文以及 Harness 生成的匿名标识和会话标识才会发送至所配置的模型服务。软件默认不启用发行方遥测。

请勿提交无权处理的个人信息、商业秘密、国家秘密或其他受保护数据。完整规则、数据删除方式和第三方处理说明以《工作台隐私政策》为准。

开源组件归属

DeepSeek Harness 采用 MIT License；内置 Rust Token Killer 采用 Apache License 2.0。第三方组件的名称仅用于说明技术来源，不表示相关项目对本产品进行背书。

工作台隐私政策

版本 2026-08-16.1

一、适用范围

本政策说明“工作台”在本机运行和调用第三方模型服务时如何处理信息。当前为功能测试版本，正式销售前将在此补充发行主体、联系地址和隐私事务联系方式。

二、本机保存的信息

软件在本机保存工作区路径、用户创建或导入的 Skill、应用设置、会话与 Token 用量记录以及运行日志。API Key 使用 Windows 安全存储加密保存，界面不会回显完整密钥。

三、发送至模型服务的信息

只有在用户使用 AI 功能时，用户输入、所选或引用的文件内容、必要的对话上下文、工具调用信息，以及 DeepSeek Harness 生成的稳定匿名用户标识和会话标识，才会发送至用户配置的模型服务。使用 DeepSeek API 时，接收方为 DeepSeek 开放平台，其处理活动同时受 DeepSeek 公布的协议和隐私政策约束。

四、敏感信息

用户应确认自己具有合法处理和发送相关信息的权限，并在发送前进行必要的筛选、脱敏和授权确认。不得提交国家秘密、无权披露的商业秘密或其他依法禁止传输的数据。

五、遥测与第三方服务

软件默认关闭发行方遥测和 RTK 遥测，不会把用户内容上传到发行方服务器。第三方模型服务仍可能根据其自身规则记录 API 请求。

六、保存期限与用户控制

本机数据持续保存至用户主动删除。用户可以在工作目录和 Skill 管理中管理文件，可以在 API 页面清除密钥，并可通过 Windows 应用数据目录清除会话和运行记录。卸载软件不会自动删除用户选择的工作目录。

七、政策更新与联系

政策发生实质变化时，软件将再次请求确认。功能测试期间请通过软件取得渠道反馈隐私问题；正式销售版将提供明确的发行主体、客服和隐私联系方式。
